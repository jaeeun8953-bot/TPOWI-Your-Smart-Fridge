# TPOWI 2.0 — 냉장고를 부탁해

2022년 TPOWI 프로젝트를 발전시킨 Gemini API 기반 Streamlit 프로토타입입니다.

## 실행
1. Python 3.10 이상 설치
2. 터미널에서 이 폴더로 이동
3. `pip install -r requirements.txt`
4. `streamlit run app.py`
5. 브라우저에서 사이드바에 Gemini API 키를 입력 (또는 `GEMINI_API_KEY` 환경변수 설정)

모델 기본값은 `gemini-3.8-flash`입니다. API 계정에서 사용 가능한 모델로 변경할 수 있습니다.

## 기능
- 보유 재료 입력
- TPOW (시간, 장소, 상황, 날씨), 조리시간, 인분, 취향 선택
- Gemini JSON 기반 3개 메뉴 생성, 추천 근거
- 보유/부족 재료 구분 (정확한 이름 일치 기준)
- 레시피 상세, 다른 메뉴 재추천, 찜 목록 JSON 내보내기

## 유의사항
- Gemini API 키가 있어야 실제 추천이 작동합니다. 이 배포물은 API 키 없이 네트워크 호출 테스트를 수행하지 않았습니다.
- AI가 생성한 레시피의 식품 안전, 알레르기 교차접촉, 의학적 적합성은 보증하지 않습니다.
- 재료 이름 일치는 간단한 규칙 기반으로, 동의어/수량은 자동 처리하지 않습니다.
- 사용자가 입력한 재료 및 선택 조건은 API로 전송됩니다. 민감한 건강정보 입력은 권장하지 않습니다.
- 냉장고 센서 자동 인식, 쇼핑몰 연동, 실시간 날씨 연동은 이번 MVP에 포함하지 않았습니다.

## UI 리뉴얼 업데이트
- 크림·코랄·오렌지·민트 그라데이션 배경, 브랜드 바, 카드 UI 및 버튼 스타일
- 레시피 완성 사진 최대 430px 표시, 카드 내부 이미지 높이 제한
- 메뉴/레시피 전환 시 화면 상단 스크롤 복원 시도 (브라우저 보안 정책에 따라 차이 가능)
- 레시피 단계별 카드 넘기기 유지
